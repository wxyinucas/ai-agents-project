W3 PROJECT BRIEF

这是一个将持续到 W16 的课程项目，不是一次性练习。
当前版本只解决一个问题：确认一份本地行情文件中有什么。

请借助本地 Agent，在自己的 students/sXX/system/ 中建立一个由 uv 管理的最小 Python 项目。sXX 是教师分配给你的公开课程代号。

项目必须满足以下要求：

1. 项目名为 quant-lab，只使用 Python 3.12.x。
2. 使用 pandas 读取 CSV；使用 pytest 运行测试；生成并保留 uv.lock。
3. 提供下面的命令：

   uv run --locked market-check <CSV 文件路径>

4. 输入文件至少包含 timestamp、symbol 和 close 三列。
5. 读取成功时，以稳定的 key=value 行报告：

   execution_mode=fixture
   symbols=<按字母排序、用英文逗号连接的股票代码>
   rows=<数据记录数，不包含表头>
   start=<最早时间>
   end=<最晚时间>
   DATA_CHECK=PASS

6. 文件不存在或缺少必要字段时，清楚说明原因，以非零状态结束，
   并在输出中包含 DATA_CHECK=FAIL；不得猜测或伪造结果。
7. 从自己的 system/ 目录运行下面的命令时，教师提供的全部公开测试必须通过：

   uv run --locked pytest -q ../../../course/week-03/tests

不要修改 course/、common/、根 .gitignore、students/README.md 或其他学生目录。
你可以在自己的 system/ 中增加测试，但本周不作要求。

本周只处理本地 fixture。不要联网，不要读取环境变量或凭证，
也不要实现下载、策略、订单、账户、网页、数据库或未来功能的空壳。
保持项目足够小，使初学者能够说明每个新增文件的职责。
不要在自己的 system/ 之外生成项目文件或未来目录。
