# W3 Starter

本目录是 W3 的教师区：

- `PROJECT_BRIEF.txt`：自然语言项目契约；
- `data/`：手动运行使用的正常样例；
- `tests/`：五项公开测试及额外 fixture；
- `report-template.md`：W3 周记录模板；
- `init-student.sh`：建立个人 `system/ + weeks/week-03/` 起点。

学生在自己的 `students/sXX/system/` 中生成项目，不修改本目录。

W3 标准版会在第三课时展示和判断结束后公布；届时学生受阻可采用它继续练习，但不能用它替代原先的尝试与个人判断。
